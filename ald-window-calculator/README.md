# ALD 공정 온도 창 계산기

2026-11-10 · 브라우저에서 바로 여는 단일 HTML 도구

전구체·반응물·기판 조합을 넣으면 목표 온도에서 ALD 공정이 되는지(가능 / 주의 / 불가)를 판정합니다. 나노라미네이트·슈퍼사이클용 공통 온도 창도 계산합니다.

| 파일 | 내용 |
|---|---|
| [`index.html`](index.html) | 계산기 본체 (라이브러리 설치 불필요) |
| [`data/ald_window_db.md`](data/ald_window_db.md) | **원본 DB**: 공정 표 + 기판 표. 계산기가 자동으로 읽음 |
| [`data/ald_window_db.xlsx`](data/ald_window_db.xlsx) | 같은 DB의 엑셀판 (드롭다운·필수칸 표시, `사용법` 시트) |
| [`tools/sync_db.py`](tools/sync_db.py) | MD ↔ 엑셀 변환·검사 스크립트 (openpyxl) |

## 기능

| 탭 | 하는 일 |
|---|---|
| 공정 진단 | 박막 → 전구체 → 반응물 → 기판 → 목표 온도를 고르면 판정과 이유를 보여줌. 같은 박막의 다른 공정, 기판 17종에 대한 적합성 표를 함께 표시 |
| 공정 DB | 35개 공정 검색·필터 (“이 온도에서 가능한 공정만”), 온도 창 막대 차트, 정렬 |
| 공통 창 · 슈퍼사이클 | 박막 2~4개를 고르면 전구체/반응물 조합을 모두 대입해 공통 창이 넓은 순으로 정렬. 기판 허용 온도·플라즈마 여부·반응물 통일 조건 |
| 데이터 관리 | DB 파일 연동, 공정·기판 직접 입력, MD·엑셀·CSV·JSON 불러오기/내보내기 |

### 판정 기준

**공정 조건**
- ALD 창 안인지, 경계까지 여유가 15 °C 미만이면 주의
- 전구체 분해 시작 온도에서 25 °C 이내면 주의, 넘으면 불가 (CVD 성분)
- 반응기 온도가 소스(캐니스터) 온도 + 10 °C보다 낮으면 응축 주의

**기판 영향**
- 기판 허용 온도 초과 시 불가, 주의 온도 초과 시 주의 (Si–H의 H 탈착, Ge의 GeO 휘발, III-V의 As 탈착 등)
- 핵생성: 비금속 표면 위 금속 공정, H 종단 표면 위 염화물 전구체, 2D 기저면, 고분자 침투, WF₆의 Si 소모
- 산화: O₃·O₂·O₂ plasma가 TiN, Cu, Ru, low-k, Ge, III-V를 산화 (Ge·III-V·Cu는 H₂O에도 표시). III-V 위 TMA는 self-cleaning 효과로 표시
- 할라이드 부산물에 의한 Cu 부식, 플라즈마 손상(low-k, 고분자, 2D)

## DB 동기화 (다른 컴퓨터에서 채우기)

원본은 `data/ald_window_db.md` 하나입니다. 계산기는 데이터를 세 겹으로 합칩니다.

```
기본 데이터 (index.html에 내장)  →  저장소 파일 (data/ald_window_db.md)  →  내 데이터 (직접 입력·불러온 파일)
```

뒤 단계가 앞 단계를 덮어씁니다. 행을 맞추는 기준은 `id`, id가 없으면 **박막 + 전구체 + 반응물 + 방식**입니다.

### 1) MD를 직접 고치는 경우

```bash
git pull
# data/ald_window_db.md 의 표에 행을 추가하거나 값을 고친다
python tools/sync_db.py check      # 필수값 확인 (선택)
python tools/sync_db.py md2xlsx    # 엑셀판도 맞추고 싶을 때 (선택)
git commit -am "ALD DB: 공정 추가" && git push
```

### 2) 엑셀로 고치는 경우

```bash
git pull
# data/ald_window_db.xlsx 를 엑셀에서 편집 (시트 이름·머리행은 그대로)
python tools/sync_db.py xlsx2md    # 엑셀 → MD 반영 (MD가 원본이므로 꼭 실행)
git commit -am "ALD DB: 엑셀에서 갱신" && git push
```

### 3) 계산기에 반영하기

| 여는 방법 | 반영 방식 |
|---|---|
| `python -m http.server` 후 `http://localhost:8000/ald-window-calculator/` | 열 때마다 `data/ald_window_db.md` 자동 읽기 (“저장소 파일 연동됨” 표시) |
| GitHub Pages | 위와 같음 |
| `index.html`을 더블클릭 (file://) | 브라우저가 파일 읽기를 막음 → 데이터 관리 탭의 **파일 불러오기**에 MD나 엑셀을 넣기 |
| claude.ai 아티팩트 | 올릴 때의 MD 스냅샷을 자동으로 읽음. 그 뒤 고친 파일은 **파일 불러오기**로 넣기 |

반대로 계산기에서 직접 입력한 내용은 **MD로 내보내기**(또는 **MD 복사**)로 받아 `data/ald_window_db.md`를 덮어쓰고 커밋하면 저장소에 남습니다. 내보낸 파일에는 기본 + 저장소 + 내 데이터가 모두 들어 있습니다.

### 파일 작성 규칙

- 공정 필수값: 박막, 전구체, 반응물, 창 하한, 창 상한 (°C). 기판 필수값: 기판, 허용 온도 (°C)
- 새 행은 `id`를 비워 두면 됩니다. 기존 행 일부만 고칠 때는 박막·전구체·반응물·방식과 바꿀 칸만 적어도 됩니다 (빈칸은 기존 값 유지)
- 방식 `열/플라즈마`, 신뢰도 `높음/중간/낮음`, 상태 `액체/고체/기체`
- 기판 표면 `OH / H / semi / metal / polymer / inert`, 예/아니오 칸은 `Y` (끄려면 `N`)
- `숨김`에 `Y`를 넣으면 기본 공정이라도 계산기에서 숨겨짐
- 머리행은 한국어 이름 외에 영문 키(`film, prec, reac, mode, tmin, tmax, …`)도 인식합니다. CSV도 같은 머리행으로 불러올 수 있습니다

## 데이터 신뢰도

기본 공정·기판 값은 ALD 리뷰 문헌에서 자주 보이는 대표 범위와 공정 상식을 정리한 것이고, **항목별 원 논문과 대조하지 않았습니다**. 각 행에 신뢰도(높음/중간/낮음)를 달아 두었고, AlN·SiNₓ·La₂O₃·Ga₂O₃·Y₂O₃·TDMAT 플라즈마 TiN 등은 “낮음”입니다. 창 경계와 분해 온도는 반응기, 도즈, 퍼지 조건에 따라 수십 °C 달라질 수 있으니 공정 설계에 쓰기 전에 원문을 확인하고 `출처` 칸에 DOI를 채워 주세요.

기판 판정은 정성 규칙입니다. 핵생성 지연이 “있다/없다”까지만 판단하고, 몇 사이클인지는 계산하지 않습니다.
